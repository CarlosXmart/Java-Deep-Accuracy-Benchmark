# Contributing

Contributions should preserve reproducibility and ground-truth discipline.

Before changing the corpus, read:

1. `docs/GROUND_TRUTH_POLICY.md`
2. `docs/CASE_AUTHORING_GUIDE.md`
3. `docs/HOLDOUT_POLICY.md`
4. `docs/CHANGE_CONTROL.md`

Every change must keep all quality gates green.

Do not accept a ground-truth or rule-oriented change whose only justification is that it raises a scanner score.
