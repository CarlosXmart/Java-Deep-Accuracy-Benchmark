# Contributing

Antes de alterar o corpus, leia:

1. `docs/GROUND_TRUTH_POLICY.md`
2. `docs/CASE_AUTHORING_GUIDE.md`
3. `docs/HOLDOUT_POLICY.md`
4. `docs/CHANGE_CONTROL.md`

Toda alteração deve manter os quality gates verdes.

Não aceite mudanças cuja única justificativa seja “o scanner passou a dar nota maior”.
