# Security Notice

Este repositório contém exemplos deliberadamente vulneráveis.

- Não implante `scan-target/` como aplicação exposta.
- Não reutilize snippets vulneráveis em produção.
- O CI compila; não executa os caminhos vulneráveis.
- Não adicione credenciais reais aos casos.
- Relatórios/scans podem conter caminhos e trechos inseguros; trate-os como artefatos internos de teste.

Para o benchmark XGuardian, processe o código somente em ambiente autorizado e controlado.
