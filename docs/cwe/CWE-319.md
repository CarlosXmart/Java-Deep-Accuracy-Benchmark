# CWE-319 — Cleartext Transmission

## Fonte oficial
- MITRE: https://cwe.mitre.org/data/definitions/319.html
- Autoridade semântica: MITRE CWE.

## Escopo
20 casos: 10 vulneráveis + 10 hard-negatives, 5 níveis.

## Vulnerável
Um token sensível é incluído no corpo ou header Authorization de uma request cujo endpoint usa `http://`.

## Seguro
O mesmo tipo de token é transportado por `https://`. O v1 evita colocar o token em query string nos hard-negatives para não introduzir uma segunda questão de segurança (exposição de segredo em URL) que contaminaria o FP da CWE-319.

## O que mede
- compreensão de scheme HTTP vs HTTPS;
- propagação de dado sensível por alias/helper/request/lambda;
- evitar alertar transporte TLS como cleartext.

## Scoring
- vulnerável sem finding na região: FN;
- seguro com finding na região: FP;
- CWE correta é avaliada separadamente por taxonomy.
